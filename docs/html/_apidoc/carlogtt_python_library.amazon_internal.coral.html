carlogtt_python_library.amazon_internal.coral module

This module contains a lightweight router to expose a Coral RPC service as REST-style routes on AWS Lambda behind API Gateway.

class carlogtt_python_library.amazon_internal.coral.CoralRouter(prefix: str | None = None)[source]

Bases: object

A lightweight router that registers REST-style routes with decorators and rewrites Coral RPC-style requests (POST to / with an X-Amz-Target header) into REST-style API Gateway events so they can be dispatched to the registered routes.

Parameters:

prefix – The path prefix applied to every registered route (e.g. “/api/v1”). Defaults to no prefix.

transform_rpc_to_rest(event: dict[str, Any]) → dict[str, Any][source]

Transform an RPC-style request to a REST-style request.

Extracts the operation name from the X-Amz-Target header and converts the RPC request (POST to /) into a REST request with proper HTTP method, path, and parameters. i.e. an event with X-Amz-Target “com.example.Service.GetUser” and body {“userId”: “123”} transforms to GET /users/123.

Parameters:

event – The API Gateway event containing the RPC-style request.

Returns:

The transformed event with REST-style routing (httpMethod, path, pathParameters, resource).

Raises:

CoralRouterError – If the operation is not found, the request body is not valid JSON, or required path parameters are missing.
