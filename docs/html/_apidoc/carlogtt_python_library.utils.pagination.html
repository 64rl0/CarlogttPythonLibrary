carlogtt_python_library.utils.pagination module

This module contains utilities for cursor-based pagination of list results using opaque, URL-safe cursor tokens.

class carlogtt_python_library.utils.pagination.Paginator(default_page_size: int = 50, max_page_size: int = 100, logger: Logger = <Logger carlogtt_python_library.utils.pagination (WARNING)>)[source]

Bases: object

A collection of utilities to paginate list results with opaque, URL-safe cursor tokens.

The cursor payload is a flat dict with str keys and str values chosen by the caller (i.e. the sort-key fields of the last item of a page). Tokens are deterministic for a given payload and must be treated as opaque by clients and passed back verbatim.

Tokens are NOT signed nor encrypted, therefore the decoded payload must be treated as untrusted client input.

Parameters:

  • default_page_size – The page size used when a request does not specify one. Must be >= 1 and <= max_page_size.

  • max_page_size – The hard upper bound for the page size.

  • logger – The logging.Logger instance to be used for logging. If not explicitly provided, the module uses Python’s standard logging module as a default logger.

Raises:

PaginationError – If the page size configuration is invalid.

decode_cursor(token: str) → dict[str, str][source]

Decode an opaque cursor token back into its payload.

Tokens are opaque and must be passed back verbatim, therefore a token that does not decode to the expected shape is treated as a caller error. Tokens are not signed, so treat the decoded payload as untrusted client input.

Parameters:

token – The opaque token to decode.

Returns:

The decoded cursor payload.

Raises:

PaginationError – If the token is not a valid pagination token.

encode_cursor(payload: dict[str, str]) → str[source]

Encode a resume-after cursor payload into an opaque, URL-safe token.

Encoding is deterministic: the same payload always produces the same token, regardless of the payload key order.

Parameters:

payload – The cursor payload. It must be a flat dict with str keys and str values.

Returns:

The opaque URL-safe token.

Raises:

PaginationError – If the payload is not a flat dict with str keys and str values.

Parameters:

max_results – The page size requested by the caller, or None if the caller did not specify one.

The effective page size.

paginate(items: Sequence[ItemType], *, cursor_factory: Callable[[ItemType], dict[str, str]], max_results: int | None = None) → tuple[list[ItemType], str | None][source]

Slice a single page off items and build the token for the next page.

The items sequence must already be sorted and filtered down to the items following the cursor of the previous page. Resume-after filtering is domain specific and is the caller responsibility.

Parameters:

  • items – The sorted sequence of the remaining items.

  • cursor_factory – A callable that receives the last item of the page and returns its cursor payload.

  • max_results – The page size requested by the caller, or None to use the configured default page size.

Returns:

A tuple of (page, next_token). next_token is None when there are no more items after this page.

Raises:

PaginationError – If the payload returned by the cursor_factory is not a flat dict with str keys and str values.
